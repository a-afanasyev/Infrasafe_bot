# BUG-192 — Group Intake: бот «не читает» группу — кириллический тег `#ариза` не распознаётся, разовый таймаут LLM = тишина — 2026-09-22

**Симптом.** profk, служебная группа «Заявки по Олмазар сити» (тег-режим):
сотрудники пишут заявки с тегом `#ариза`, бот не реагирует. Последняя заявка
из группы создана 2026-09-12.

**Диагноз по факту (ssh profk, read-only).** Контейнер `uk-group-intake-bot`
жив, polling работает (webhook не установлен, очередь updates пустая, privacy
выключен, `can_read_all_group_messages=true`). За сутки до классификатора дошло
ровно одно сообщение (dedup-ключ `gint:seen` в Redis один), и оно упало по
таймауту 8 с к Anthropic. При этом ключ валиден, пять реальных вызовов haiku с
хоста укладываются в 0,9–1,1 с — сбой был разовым (у обоих ботов за сутки по
7–9 «Connection reset by peer» к Telegram, фон хостинга).

**Корни (два).**

1. `uk_management_bot/database/models/monitored_group.py`:
   `REQUEST_TAGS = ("#заявка", "#ariza")` — только латинский узбекский тег.
   Сообщение с `#ариза` (кириллицей) в тег-режиме отбрасывается молча ещё до
   логов, БД и LLM — «бот не видит» неотличимо от «сообщений не было».
2. `uk_management_bot/services/group_intake/classifier.py` — один вызов без
   ретрая; `handlers/group_intake.py` — в тег-режиме `PROCESSING_ERROR`
   означал тишину. Разовый обрыв сети ронял помеченную заявку без следа для
   автора, а dedup не давал обработать то же сообщение повторно.

**Правка.**

- `REQUEST_TAGS` += `#ариза`, `#zayavka` (casefold, как раньше).
- Классификатор: один повтор при transient-сбое (таймаут, обрыв соединения,
  429/5xx Anthropic); 4xx/логические ошибки не повторяются. Лог-маркер
  `group_intake.llm_retry`.
- Хендлер: в тег-режиме при итоговом `PROCESSING_ERROR` автору уходит
  `group_intake.classifier_unavailable` (ru/uz) — просьба отправить ещё раз;
  без тега прежняя тишина.

Тесты (красные до правки): `uk_management_bot/tests/handlers/test_group_intake_tag_resilience.py`
(теги `#ариза`/`#zayavka` проходят пайплайн, ответ автору при сбое, тишина без
тега, ключ локали в обоих языках), `tests/services/test_group_intake_classifier.py`
(ретрай при `TimeoutError`/`ConnectionResetError`, два сбоя → `PROCESSING_ERROR`,
`ValueError` не повторяется). Старый `test_tagged_processing_error_stays_silent`
переписан под новый контракт (`..._asks_to_resend`).

Слепая зона остаётся: отсев «нет тега» и «автор не сотрудник» по-прежнему
бесшумен и не логируется — по дизайну (приватность/стоимость).

Раскатка: `group-intake-bot` на profk (код в образе `app`); core-четвёрка
пересобирается на обоих хостах для единства коммита.

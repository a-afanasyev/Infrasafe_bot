## Правило «живого» ключа

Консервативно — сомнение трактуется в пользу «живой»:

1. **literal** — полное имя ключа есть как токен в любом git-файле кода/конфига
   (Python — строковые константы и части f-строк через `ast`; `.ts/.tsx/.js/.json/.yml/.sh/.sql/...`
   — токены `[\w.]+`). Тесты считаются ссылками. `docs/` и `*.md` — нет.
2. **dynamic** — ключ подпадает под шаблон из кода: f-строка / конкатенация /
   `"...{}".format`, чьи константные части похожи на ключ, либо прод-константа-префикс
   с `.` на конце (`KEY = "elevators.bot."`).
3. **plural** — `<ключ>_plural(_many)` живого ключа (таких не нашлось).

Динамические префиксы (константы): `elevators.bot.`, `elevators.notify.`, `elevators.remind.`,
`elevators.status.`, `group_intake.elevator.`, `specializations.`.

Динамические шаблоны (f-строки): `access_control.{direction,duration,pass_type,relation}.*`,
`access_control.dispute.answered_*`, `access_levels.*`, `address_apartments.handlers.*`,
`address_errors.*`, `comments.type_*`, `document_types.*`, `group_intake.*`, `info_types.*`,
`materials.units.*`, `months.*`, `notify.reason.*`, `requests.elevator.*`, `roles.*`,
`shift_management.*`, `shift_transfer.{errors,handlers}.*`,
`shift_transfer.{handlers,keyboards}.{reason,urgency,status,transfer_status}_*`,
`user_management.*_users`, `user_mgmt.handlers.doc_type.*`, `user_status.*`, `user_statuses.*`,
`verification.{status,document_status,document_types}.*`, `web_notifications.document_types.*`.

Шаблоны прод-кода, начинающиеся с переменной (`f"{x}.{y}"`), сверены вручную — это
HMAC-сообщения вебхуков, пути конфигурации напоминаний, имена файлов и git-диапазоны,
не ключи локали. Callback-префиксы без точки (`"request_"`, `"shift_"`, `"user_"`)
пространством ключей не считаются; константы из тестов вида `startswith("admin.")`
(проверки «ключ не протёк») — тоже.

## Ручные проверки

- Выписаны все 91 вызов `get_text(<не литерал>)` в прод-коде; источники ключа проверены
  выборочно по каждому виду (executor/materials, клавиатуры onboarding/requests/admin,
  language_helpers, button_texts, notification_service, elevators) — ключи приходят из
  словарей/констант с полными литералами (`CATEGORY_KEYS`, `URGENCY_KEYS`,
  `document_name_keys`, `_DENY_KEYS`, возвраты `"requests.request_not_found"` …) или
  из префиксов, учтённых выше.
- Ключи локали в БД не хранятся (единственный `category_key` — канон-токен, маппится
  через `CATEGORY_KEYS`). Фронт использует свои `frontend/src/i18n/locales`, бот-локали
  не читает (его токены всё равно учтены как ссылки).
- 227 мёртвых ASCII-ключей, чей хвост совпадает с какой-либо строковой константой,
  разобраны: совпадения случайные (колонки БД, callback_data, WS-события `shift.updated`).

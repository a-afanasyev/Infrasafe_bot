Дизайн-превью фронтенда PROFK по брендбуку — светлая «инженерная» тема, зелёный акцент, Montserrat + Open Sans. Это статичные макеты для приёмки (не рабочее приложение). После утверждения тема применяется параллельно с InfraSafe через сборку VITE_BRAND=profk.

# Бренд PROFK — исходники

Что здесь лежит (`AUD5-JUNK-4`, решение принято 2026-07-27):

| Файл | Что это |
|---|---|
| `brandbook.md` | брендбук: палитра, типографика, правила применения |
| `logo-small.png` | компактный логотип |
| `preview/` | HTML-макеты экранов (`profk.css` + страницы), по которым сверялась вёрстка |

**Рабочие ассеты фронта живут не здесь**, а в `frontend/public/profk-logo.svg` — сборка
берёт их оттуда. Каталог с брендом ни на что не собирается и ни во что не импортируется:
это документация дизайна.

## Чего здесь намеренно нет

Крупные растровые мастера (`Big_logo.png`, `ProFKBB.png`, `Single_logo_circle.png`,
`circle-logo.png` — суммарно ~17.5 МБ) в git **не внесены**: это экспорты, репозиторий
они утяжеляют навсегда, а сборка их не использует.

⚠️ Обратная сторона решения: у них нет резервной копии в этом репозитории. Если
единственный экземпляр лежит на рабочей машине — держите его в облачном хранилище
вместе с исходниками из дизайн-инструмента.

ПОЛНОЕ ОПИСАНИЕ БРЕНДБУКА ДЛЯ СОЗДАНИЯ ФРОНТЕНДА PROFK
1. ЛОГОТИП И ВАРИАЦИИ
Эта секция определяет использование логотипа в цифровой среде.

Основной горизонтальный логотип (full logo): Используется в шапке сайта, на экранах загрузки, в подвале (footer) и в официальных цифровых коммуникациях. Текст «PROFK» и дескриптор «PRO FACILITY KOMMUNAL» должны быть четкими и читабельными. Обязательно соблюдать охранное поле.

Минималистичный значок (icon only): Идеально подходит для фавиконок (favicon), мобильных приложений, аватарок в социальных сетях и как элемент интерактивных карт или схем обслуживания.

Примеры использования в интерфейсе: Показано размещение логотипа в шапке веб-сайта на десктопе и мобильном устройстве.

2. ЦВЕТОВАЯ ПАЛИТРА И СТАТУСЫ
Определяет основные, фоновые и, что критично для фронтенда, статусные цвета для обеспечения обратной связи.

Основные цвета:

Угольный (#333333): Для основного текста, заголовков и контуров зданий в логотипе.

Зеленый (#44c24a): Акцентный цвет для кнопок действий, ссылок, значка листа в логотипе и статусных элементов.

Фоновые цвета: Светло-серый (#f5f5f5) и чистый белый (#ffffff) для создания чистого и "инженерного" вида.

Статусные цвета (Feedback Colors):

Успех (Success): Зеленый (#44c24a) — для уведомлений об успешной подаче заявки или оплате.

Ошибка (Error): Красный (#d9534f) — для валидации форм и предупреждений.

Предупреждение (Warning): Желтый (#f0ad4e) — для уведомлений, требующих внимания.

Информация (Info): Синий (#5bc0de) — для общих информационных сообщений.

3. ТИПОГРАФИКА И ИЕРАРХИЯ
Определяет шрифтовые гарнитуры и правила их использования для создания четкой информационной структуры.

Шрифтовые гарнитуры: Рекомендуется использовать современные, открытые гротески, хорошо читаемые на экранах (например, Montserrat для заголовков и Open Sans/Montserrat Regular для текста).

Иерархия (Typography Hierarchy):

Заголовки (H1): 32px, жирный (#333333). Например, для названий разделов.

Заголовки (H2): 24px, жирный (#333333). Для подзаголовков.

Заголовки (H3): 18px, жирный (#333333). Для мелких заголовков или карточек.

Основной текст (Body): 16px, нормальный (#333333), с хорошим межстрочным интервалом (1.5).

4. ЭЛЕМЕНТЫ ИНТЕРФЕЙСА (UI KIT)
Примеры конкретных компонентов пользовательского интерфейса, готовых к реализации.

Кнопки (Buttons):

Основная (Primary): Зеленая (#44c24a), со скругленными углами и белым текстом. Для главных действий.

Вторичная (Secondary): Серая или контурная, для альтернативных действий.

Текстовая (Text Link): Ссылка зеленого цвета без фона.

Поля ввода (Inputs): Чистые, с четкими границами (#dcdcdc). Показаны состояния: Пустое, С фокусом (синяя обводка), С иконкой.

Карточка услуги (Service Card): Интегрирует логотип и иконки. Показаны карточки «Сантехник» и «Электрик», использующие графику из брендбука (спецодежда), с кнопкой действия.

Иконки (Icons): Контурные иконки в едином стиле (дом, гаечный ключ, молния, лист) для визуализации услуг.

Выпадающий список (Dropdown): С четкими пунктами меню.

5. СЕТКА И ОТСТУПЫ (LAYOUT & SPACING)
Определяет структуру размещения элементов на экране.

Базовая сетка (Base Spacing): Рекомендуется использовать кратные отступы (например, 4px, 8px, 16px, 24px, 32px) для создания предсказуемого и гармоничного макета.

Сетка колонок: Для десктопа рекомендуется 12-колоночная сетка.

Пример макета: Показан макет сетки с обозначением колонок и отступов.

Это руководство обеспечивает полную визуальную согласованность фронтенда PROFK, делая его удобным для пользователей и разработчиков.

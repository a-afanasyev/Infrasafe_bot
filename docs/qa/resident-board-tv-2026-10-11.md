- Телефон сохраняет обычную вертикальную страницу; статусы, заявки и дни недели переносятся без горизонтального scroll.
- API, polling (45 секунд), ключи запросов, credentials, server scope и обезличивание не менялись. Новые персональные поля не запрашиваются.
- KPI «Выполнено за месяц» исправлен на «Выполнено и принято»: API отдаёт текущие status_counts без месячного фильтра. Суммируются только Выполнена и Принято. Исполнено исключено: public/router.py сворачивает туда Возвращена. Выполнение и приёмка остаются отдельными колонками.

## Локальный просмотр

В каталоге `frontend`:

```sh
npm ci
npm run dev:profk -- --host 127.0.0.1 --port 5178 --strictPort
```

Открыть `http://127.0.0.1:5178/uk/resident-board` на 1920×1080 / 1366×768.
Обычная версия: `http://127.0.0.1:5178/uk/resident-board?mode=page`.
Vite уже настроен проксировать `/uk/api` в локальный API `localhost:8085`; для живых данных API должен быть запущен штатно. При его отсутствии интерфейс показывает отсутствие данных. Тестовые данные в production не добавлены.

Для повторения browser smoke на этом Mac: запустить Vite, затем в рабочей копии UK выполнить `node qa/board-browser.mjs`. Скрипт использует установленный Playwright из исходного UK/tests/e2e/node_modules и не изменяет БД.

# BUG-191 — редактор витрины: предупреждение «несохранённые изменения» при уходе всегда — 2026-09-18

**Симптом.** Открыть «Редактор витрины», ничего не менять, закрыть вкладку или
перезагрузить страницу — браузер спрашивает «Изменения могут не сохраниться».
После «Сохранить» — то же самое.

**Корень.** `frontend/src/pages/BoardEditorPage.tsx`: `isDirty` сравнивал
`JSON.stringify(draft)` с сырым ответом `GET /public/board-config`. Ответ несёт
`display_tz` (ARCH-137 B5), а черновик сеется через `toEditableBoardConfig`,
который это поле снимает — строки не равны никогда, `beforeunload`-guard
(FE-043) стоял постоянно. Ремонт WR-09 (пересев после сохранения) проблему не
закрывал по той же причине.

**Правка.** Сравнение с `toEditableBoardConfig(serverConfig)` — той же формой,
из которой посеян черновик.

Тест: `frontend/src/pages/BoardEditorPage.test.tsx` — «„Сбросить" возвращает
серверные значения; beforeunload-guard только при несохранённых правках»
(красный до правки: `defaultPrevented === true` сразу после загрузки; зелёный
после). Найден в TEST-068 при покрытии страницы.

Раскатка: только frontend (обе бренд-сборки).

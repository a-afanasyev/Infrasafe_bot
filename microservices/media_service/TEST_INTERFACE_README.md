# 🧪 Тестовый интерфейс Media Service

## 📋 Описание

Простой HTML интерфейс для тестирования основного функционала Media Service без необходимости использования API клиентов или командной строки.

## 🚀 Запуск

### 1. Убедитесь, что Media Service запущен

```bash
cd microservices
docker-compose ps media-service
```

Сервис должен быть в статусе `healthy` и доступен на порту `8004`.

### 2. Откройте тестовый интерфейс

Просто откройте файл `test_interface.html` в браузере:

```bash
open test_interface.html
```

Или перетащите файл в окно браузера.

## ✨ Доступный функционал

### 🏥 Проверка статуса сервиса

- **Автоматическая проверка** при загрузке страницы
- **Ручная проверка** через кнопку "Проверить статус"
- Отображение:
  - Статус сервиса (online/offline)
  - Версия сервиса
  - Время ответа

### 📤 Загрузка файлов

**Поддерживаемые типы файлов:**
- Изображения: JPEG, PNG, GIF, WebP
- Видео: MP4, WebM
- Документы: PDF

**Параметры загрузки:**
- Номер заявки (обязательно)
- Категория файла
- Описание
- Теги через запятую
- Превью изображения перед загрузкой

**Пример использования:**
1. Нажмите "Выберите файл"
2. Выберите изображение или документ
3. Заполните номер заявки (например: `TEST-001`)
4. Выберите категорию
5. Добавьте описание и теги (опционально)
6. Нажмите "📤 Загрузить файл"

### 🔍 Поиск файлов

**Параметры поиска:**
- Номер заявки
- Категория
- Теги

**Результаты поиска включают:**
- ID файла
- Имя файла
- Номер заявки
- Категория
- Размер файла
- Дата загрузки

**Пример использования:**
1. Введите номер заявки (например: `TEST-001`)
2. Выберите категорию (опционально)
3. Укажите теги для поиска (опционально)
4. Нажмите "🔍 Найти файлы"

### 📊 Статистика

**Отображаемые метрики:**
- Общее количество файлов
- Суммарный размер файлов
- Количество уникальных заявок

**Использование:**
- Нажмите "📊 Получить статистику"

## 🔧 Возможные проблемы

### CORS ошибки

Если видите ошибку CORS в консоли браузера:

1. Проверьте настройки CORS в `app/main.py`
2. Убедитесь, что `allow_origins=["*"]` включен для разработки

### Сервис недоступен

Если сервис показывается как недоступный:

```bash
# Проверьте статус контейнера
docker-compose ps media-service

# Проверьте логи
docker-compose logs media-service

# Перезапустите сервис
docker-compose restart media-service
```

### Ошибки загрузки файлов

**Размер файла превышает лимит:**
- Проверьте `MAX_FILE_SIZE` в настройках
- По умолчанию: 50 MB

**Тип файла не поддерживается:**
- Проверьте `ALLOWED_FILE_TYPES` в настройках
- Поддерживаемые типы: `image/*`, `video/*`, `application/pdf`

## 📝 Примеры тестовых сценариев

### Сценарий 1: Загрузка фото заявки

```
1. Выберите изображение (JPG/PNG)
2. Номер заявки: TEST-001
3. Категория: "Фото заявки"
4. Описание: "Повреждение стены"
5. Теги: "фото, повреждение, срочно"
6. Загрузите файл
7. Проверьте успешный ответ с ID файла
```

### Сценарий 2: Загрузка фото до/после работ

```
1. Выберите изображение "до ремонта"
2. Номер заявки: TEST-002
3. Категория: "До работ"
4. Загрузите

5. Выберите изображение "после ремонта"
6. Номер заявки: TEST-002
7. Категория: "После работ"
8. Загрузите
```

### Сценарий 3: Поиск по заявке

```
1. Перейдите в раздел "Поиск файлов"
2. Введите номер заявки: TEST-001
3. Нажмите "Найти файлы"
4. Проверьте список найденных файлов
```

### Сценарий 4: Проверка статистики

```
1. Загрузите несколько файлов с разными заявками
2. Перейдите в раздел "Статистика"
3. Нажмите "Получить статистику"
4. Проверьте количество файлов и размер
```

## 🛠️ API Endpoints

Интерфейс использует следующие endpoints:

```
GET  /health                    - Статус сервиса
GET  /api/v1/health            - Детальный статус
POST /api/v1/media/upload      - Загрузка файла
GET  /api/v1/media/search      - Поиск файлов
GET  /api/v1/media/statistics  - Статистика
```

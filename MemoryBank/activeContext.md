1. **Назначение группам исполнителей** - заявка назначается группе исполнителей с нужной компетенцией (сантехники, электрики и т.д.)
2. **Адресное назначение** - заявка прикрепляется к конкретному исполнителю лично
3. **Видимость в "Мои заявки"** - заявки попадают в список исполнителя только после установки статуса "В работе" менеджером

#### 🔄 **Управление статусами заявок:**
1. **"Закуп"** - исполнитель может перевести заявку в статус "закуп" с обязательным комментарием о необходимых материалах
2. **"В работе"** - менеджер возвращает заявку в работу после получения закупленных материалов
3. **"Уточнение"** - менеджер или исполнитель может запросить уточнение с комментарием
4. **"Исполнено"** - исполнитель завершает работу
5. **"Принято"** - заявитель принимает выполненную работу (финальный статус)

#### 🔄 **Система комментариев:**
- Все комментарии сохраняются в заявке
- Комментарии привязаны к изменениям статуса
- История комментариев доступна всем участникам

#### 🔄 **Отчеты и уведомления:**
- Отчет отправляется заявителю при статусе "Исполнено"
- Предложение "принять" заявку
- Уведомления о всех изменениях статуса

#### **2. Сервис генерации номеров:**
```python
@staticmethod
def generate_next_number(creation_date: Optional[date] = None, db: Optional[Session] = None) -> str:
    if creation_date is None:
        creation_date = date.today()
    
    date_prefix = creation_date.strftime('%y%m%d')
    pattern = f"{date_prefix}-%"
    
    # Атомарный поиск следующего номера
    last_request = db.query(Request).filter(
        Request.request_number.like(pattern)
    ).order_by(Request.request_number.desc()).first()
    
    if last_request:
        last_sequence = int(last_request.request_number.split('-')[1])
        next_sequence = last_sequence + 1
    else:
        next_sequence = 1
        
    return f"{date_prefix}-{next_sequence:03d}"
```

# 📱 Техническое задание - WebApp (Веб-приложение)

**Версия**: 1.0.0
**Дата**: 09.10.2025
**Статус**: Детальная спецификация
**Приоритет**: P1

---

## 📌 Обзор

### Назначение (Q12.1)
Веб-приложение для управления заявками в управляющей компании с полным функционалом Telegram бота + расширенные возможности для менеджеров и руководителей.

**Принято решение**: WebApp в первую очередь для менеджеров и администраторов

### Целевая аудитория
1. **Менеджеры** (основная) - управление заявками, контроль исполнителей
2. **Администраторы** (основная) - полное управление системой
3. **Исполнители** (вторичная) - просмотр заявок и отчетность
4. **Жители** (будущее) - создание заявок, если не используют Telegram

### Scope MVP
- ✅ Расширенный функционал управления (не урезанный)
- ✅ Все возможности управления заявками
- ✅ Аналитика и отчеты
- ✅ Управление пользователями
- ✅ Управление сменами
- ✅ Настройки системы
- ✅ Адаптивный дизайн (desktop + mobile)

### Ключевые отличия от Telegram бота
- 📊 Дашборды и аналитика в реальном времени
- 📈 Детальные отчеты и экспорт данных
- 🗓️ Расширенное управление сменами
- 📋 Табличные представления с фильтрацией
- 💼 Функции управления персоналом
- 📱 Адаптивный дизайн для всех устройств

## 🎯 Функциональные требования

### 0. Адаптивный дизайн (Q12.1)

**Требования к responsive design**:

**Desktop версия** (≥1280px):
- Полная ширина интерфейса
- Multi-column layout
- Расширенные таблицы
- Sidebar меню
- Всплывающие модальные окна

**Tablet версия** (768px - 1279px):
- Адаптивная сетка 2 колонки
- Складывающееся меню
- Упрощенные таблицы с горизонтальным скроллом
- Drawer меню

**Mobile версия** (< 768px):
- Single column layout
- Hamburger меню
- Карточный вид вместо таблиц
- Bottom navigation bar
- Touch-optimized controls
- Вертикальная ориентация приоритетна

**Progressive Web App (PWA)**:
- Установка на home screen
- Offline capability (базовый функционал)
- Push notifications (при поддержке браузера)
- App-like experience

### 1. Аутентификация и авторизация

#### 1.1 Способы входа (для менеджеров/админов)
```
✅ Email + пароль
✅ Telegram OAuth (Single Sign-On с ботом)
✅ Двухфакторная аутентификация (обязательно для админов)
```

**Не включено в MVP** (решение Q12.1):
- ❌ Телефон + SMS код (для жителей в будущем)
- ❌ QR-код для быстрого входа (Phase 2+)

#### 1.2 Регистрация
**MVP Scope**:
- Только для сотрудников (менеджеры, админы)
- Создание учетных записей через админку
- Приглашения по email с временным паролем
- Обязательная смена пароля при первом входе

**Не включено в MVP**:
- ❌ Самостоятельная регистрация жителей (только через Telegram бот)
- ❌ Привязка к квартире (жители используют бот)

#### 1.3 Профиль пользователя
- Личные данные (ФИО, телефон, email)
- Привязанные квартиры
- Активные роли
- История активности
- Настройки уведомлений
- Выбор языка интерфейса (RU/UZ/EN)
